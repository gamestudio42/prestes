# Comando de companhia / Comando de companhia

Cite: A game organization

## English

The command group of a legalist company. Macaulay gives units and totals, not
small-unit tables, so the grouping is ours. Part of the legalist forces.

## Português (BR)

O grupo de comando de uma companhia legalista. Macaulay dá unidades e totais,
não quadros de pequenas frações, e o agrupamento é nosso. Parte das forças
legalistas.
