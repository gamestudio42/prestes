# Image permission requests

These are drafts that the owner will send. Claude does not send them. Each file
is one request to one rights holder. Before sending, the owner fills in the
signature and checks the contact address on the institution's own site; the
addresses are not filled in here on purpose.

Until permission is granted, an image under request is used **only on the
owner's machine**. It is never committed and never published. See
`openspec/changes/complete-books-and-bibliography/design.md`, D3a. When an
answer arrives:

1. Save it, without personal data, in `docs/rights/grants/<holder>-<date>.md`,
   with the date, who signed it, the terms and the required credit line.
2. Change the image's register row from `permission-pending` to
   `permission-granted`, and cite the grant file.
3. Move the file from `art-src/compendium-pending/` into
   `apps/game/public/assets/compendium/`.

A refusal goes in the same folder, and the image leaves the game.
