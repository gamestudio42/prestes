## Original model sources

The models are built by Blender Python scripts in `art-src/blender/`
(`pnpm art`, Blender located like Aseprite or through `BLENDER`), which save
editable `.blend` sources next to their exports (`art-src/characters/`,
`art-src/environment/`; the `.blend` files are gitignored and regenerated by
`pnpm art`). `pnpm models` prunes and deduplicates the exported `.glb` files
into `apps/game/public/models/`. The exports and textures are committed, so
building and testing never need Blender. All models and textures are original;
no third-party model is used.

## Menu gramophone recordings

The 17 recordings below are public domain; Discografia Brasileira marks each
recording with the year it entered the public domain. The project owner
supplied the files and verified the set on 2026-11-06. The source pages are
the Discografia Brasileira post
[Novidade na Discografia Brasileira](https://discografiabrasileira.com.br/posts/248200/novidade-na-discografia-brasileira-mais-de-5-mil-gravacoes-em-dominio-publico-podem-ser-baixadas-aqui-no-site)
and the per-recording page linked from each title. Titles, composers,
performers, labels, catalog numbers and source URLs are also recorded in
`apps/game/src/audio/gramophone-tracks.ts`.

The source files stay in the gitignored `gramofone/` folder; the committed
copies in `apps/game/public/music/` are mono 24 kbps MP3 at 22.05 kHz,
high-passed at 120 Hz, low-passed at 3.5 kHz, normalized to -20 LUFS with a
-2 dB true peak, and stripped of tags. `pnpm optimize:music` rebuilds them
from the source folder.

## Rules

- Do not describe a placeholder as finished art.
- Record every third-party asset with source and licence before committing.
- Do not copy Vazante assets; its rendering techniques are reimplemented with
  attribution in `docs/decisions/0002-visual-language.md`.
- Book scans and extracted maps stay in `livros/` and are never committed.
- Character source `.blend` files are binary and may be large; keep a backup and
  remove the ignore rule deliberately if a source file is versioned.
